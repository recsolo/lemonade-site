# Sweet Sensation Lemonade & BBQ 🍋🔥

Landing page for Indy's pop up shop for fresh lemonade & BBQ.

A single static page (`index.html`) — no build step required.

## Deploy on Vercel

1. Go to [vercel.com/new](https://vercel.com/new) and sign in with GitHub.
2. Import the `lemonade-site` repository.
3. Leave all settings at their defaults (Framework Preset: **Other**, no build command) and click **Deploy**.

Every push to the production branch will redeploy automatically.

## Local preview

Open `index.html` in a browser, or run:

```sh
npx serve .
```
